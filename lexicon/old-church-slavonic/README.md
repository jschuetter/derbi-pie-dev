# Lexicon - Old Church Slavonic
**Enwiktionary Dump**

This directory contains entries in both JSONL and CSV format of Old Church Slavonic, derived from [Kaikki](https://kaikki.org/dictionary/Old%20Church%20Slavonic/index.html). See `~/lexicon/kaikki-data` for parser scripts and further information.

*Language parameters:*
- `lang = "Old Church Slavonic"`
- `lang_code = "cu"`

## Notes
There is no gloss listed in the JSONL for the following lemmas: 
- -мо
- -гда
- котерꙑи
- продьлити

IPA transcription is only provided for a few entries in the Wiktextract data.
