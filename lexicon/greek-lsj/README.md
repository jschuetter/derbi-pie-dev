# Lexicon - Greek
***Liddell-Scott-Jones Ancient Greek Lexicon***

This directory contains an XML to CSV parser (`xmlreader.py`) for the Liddell-Scott-Jones Ancient Greek Lexicon. These files also being sourced from the [Perseus Digital Library](https://www.perseus.tufts.edu/hopper/), the reader is based heavily on the [xmlreader script for Latin](https://github.com/jschuetter/derbi-pie-dev/blob/main/lexicon/latin-lewis-short/xmlreader.py).

The XML files were sourced from Giuseppe G. A. Celano's [LSJ_Additions repository](https://github.com/gcelano/LSJ_additions) on GitHub, cloned on 2026-06-06.
The parser script is the original work of [Jacob Schuetter](https://github.com/jschuetter) for the DERBi PIE project.
