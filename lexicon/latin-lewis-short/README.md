# Lexicon - Latin
***A Latin Dictionary* (Lewis & Short)**

This directory contains an XML to CSV parser (`iterReader.py`) for the Lewis and Short Latin lexicon. The output is stored here in two parts, `lewis-short-1.csv` and `lewis-short-2.csv` for reasons of file size, which is also why the original input XML is not stored here.

The [XML file](https://github.com/PerseusDL/lexica/blob/master/CTS_XML_TEI/perseus/pdllex/lat/ls/lat.ls.perseus-eng2.xml) was sourced from the [Perseus Digital Library](https://www.perseus.tufts.edu/hopper/) on GitHub.
The parser script is the original work of [Jacob Schuetter](https://github.com/jschuetter) for the DERBi PIE project.
